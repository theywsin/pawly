# ماژول جلسات و مصوبات (`meetings`)

| بخش | توضیح |
|---|---|
| جلسه | موضوع، نوع، تاریخ شمسی و ساعت (به وقت تهران، ذخیره UTC)، محل، نشانی آنلاین، پروژه مرتبط (از سرویس `projects.projects`) |
| دعوت | همکاران (اعلان دعوت) و مدعوین خارج از سازمان؛ برگزارکننده خودکار حاضر است |
| دستور جلسه و صورت‌جلسه | بندهای دستور جلسه؛ متن صورت‌جلسه و حضور و غیاب؛ «نهایی کردن» صورت‌جلسه و فهرست مصوبات را قفل می‌کند |
| مصوبات | متن، مسئول اجرا (اعلان)، مهلت؛ پیگیری توسط مسئول: انجام (با تاریخ)، لغو، گزارش پیگیری |
| گزارش و یادآوری | فهرست مصوبات با فیلتر معوق/مال من؛ کار زمان‌بندی‌شده یادآوری پیش از مهلت (تنظیمات: ۲ روز) و یک بار هنگام معوق شدن |
| داشبورد | «جلسات پیش‌رو» (۷ روز) و «مصوبات معوق» |

## مجوزها
`meetings.meeting.view` / `meetings.meeting.manage` (company / own: جلساتی که برگزارکننده یا مدعو آن هستید؛ ویرایش فقط برگزارکننده)، `meetings.resolution.update` (own: مصوبات خودتان). نقش‌ها: «دبیر جلسات» و «شرکت‌کننده جلسات».

## محدودیت‌ها
- منطقه زمانی ثابت تهران است (A34)؛ تقویم/دعوت‌نامه iCal و یکپارچگی با تقویم‌های خارجی ندارد.
- مصوبات به «وظایف» هسته متصل نمی‌شوند؛ پیگیری در خود ماژول انجام می‌شود.
- چاپ/PDF صورت‌جلسه هنوز ساخته نشده است.
