# ماژول فروش و مشتریان (`crm`)

CRM مهندسی برای شرکت‌های مشاور و پیمانکار: از سرنخ تا فرصت فروش، پیشنهاد فنی و مالی و گزارش فروش.

## قابلیت‌ها

| بخش | توضیح |
|---|---|
| مشتری | شخص یا شرکت؛ شناسه/کد ملی، کد اقتصادی، حوزه فعالیت، تماس، نشانی، مسئول، یادداشت؛ هشدار نام تکراری |
| مخاطب | نام، سمت، موبایل (نرمال‌سازی‌شده)، تلفن، ایمیل؛ **هشدار** (نه منع) برای موبایل تکراری در سازمان |
| سابقه ارتباط | تماس، جلسه، بازدید، ایمیل، پیام، یادداشت — برای مشتری، سرنخ یا فرصت؛ تعیین تاریخ پیگیری بعدی |
| سرنخ | منبع (وب‌سایت، معرفی، مناقصه، نمایشگاه، …)، نیاز، بودجه تخمینی، امتیاز ۰ تا ۱۰۰، مسئول، تاریخ تماس بعدی، وضعیت؛ «از دست رفت» با دلیل اجباری؛ اولین ارتباط وضعیت «جدید» را به «تماس گرفته شد» می‌برد |
| تبدیل سرنخ | ساخت (یا انتخاب) مشتری، مخاطب و فرصت در اولین مرحله باز؛ سابقه ارتباط سرنخ به مشتری منتقل می‌شود |
| قیف فروش | مراحل قابل تنظیم برای هر شرکت (نام، ترتیب، احتمال، نوع باز/برنده/از دست رفته، بایگانی)؛ قیف همیشه دست‌کم یک مرحله باز، یک برنده و یک از دست رفته دارد؛ قیف پیش‌فرض در اولین استفاده ساخته می‌شود |
| فرصت | مشتری، مخاطب، ارزش، احتمال (پیش‌فرض: احتمال مرحله)، تاریخ پیش‌بینی بستن، مسئول، پیگیری بعدی، اتصال به پروژه و قرارداد؛ تابلوی مراحل با جابه‌جایی از طریق فهرست انتخاب (قابل استفاده با صفحه‌کلید)؛ برنده/از دست رفته فرصت را می‌بندد (دلیل از دست رفتن اجباری)؛ تاریخچه مراحل |
| پیشنهاد فنی و مالی | فنی/مالی/فنی و مالی؛ **هر بازنگری نسخه جدید** با مبلغ، تاریخ اعتبار و شرح؛ نسخه ارسال‌شده تغییر نمی‌کند؛ ثبت ارسال، پذیرش یا رد؛ نمایش «منقضی» پس از تاریخ اعتبار |
| یادآوری | کار زمان‌بندی‌شده: اعلان روز پیگیری به مسئول سرنخ/فرصت (یک بار در روز) |
| گزارش فروش | در بازه دلخواه: تعداد سرنخ و نرخ تبدیل، فرصت‌های برنده و نرخ موفقیت، قیف فعلی (تعداد، ارزش، ارزش وزنی)، منابع مؤثر جذب (سرنخ، تبدیل، ارزش برنده)، عملکرد کارشناسان، دلایل از دست رفتن |
| داشبورد | «قیف فروش» و «پیگیری‌های امروز و معوق» (برای خود کاربر) |

## مجوزها
| کلید | محدوده |
|---|---|
| `crm.account.view` / `crm.account.manage` | company / own (مشتریانی که مسئول یا ثبت‌کننده آن هستید) |
| `crm.pipeline.view` / `crm.pipeline.manage` | company / own — سرنخ، فرصت و پیشنهاد |
| `crm.report.view` | company |
| `crm.settings.manage` | company — مراحل قیف |

نقش‌های پیش‌فرض: «مدیر فروش» (`crm.*`) و «کارشناس فروش» (مشاهده همه مشتریان؛ مدیریت مشتری و سرنخ/فرصت‌های خودش).

## وابستگی‌ها
- **اختیاری:** `projects` و `contracts` (اتصال فرصت به پروژه و قرارداد از طریق سرویس‌های عمومی آن‌ها).
- **سرویس عمومی:** `crm.accounts@1.0.0` — `search(q, limit)`، `get(id)`؛ قراردادها و پروژه‌ها برای انتخاب کارفرما از آن استفاده می‌کنند.
- **رویدادها:** `crm.lead.converted`، `crm.opportunity.won`.

## محدودیت‌های نسخه ۱
- درخواست‌های فرم دمو/تماس سایت (لید پلتفرم) به CRM سازمان‌ها منتقل نمی‌شوند؛ آن‌ها لیدهای فروش خود پلتفرم‌اند.
- پیوست فایل به پیشنهاد، چاپ/PDF پیشنهاد و خروجی Excel گزارش‌ها هنوز ساخته نشده‌اند.
- جابه‌جایی کارت با کشیدن و رها کردن (drag & drop) پیاده نشده؛ تغییر مرحله با فهرست انتخاب است.
