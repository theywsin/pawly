# ماژول بانک رزومه و استخدام (`recruitment`)

| بخش | توضیح |
|---|---|
| رزومه | اطلاعات تماس (همراه نرمال‌شده یا ایمیل، دست‌کم یکی)، شهر، موقعیت مورد نظر، حقوق مورد انتظار، آمادگی شروع، منبع، معرف، نمونه‌کار، خلاصه؛ سوابق کاری با تاریخ، تحصیلات، پروژه‌ها، مهارت/نرم‌افزار/گواهینامه/زبان با سطح ۱ تا ۵. **سن، تاریخ تولد، جنسیت، تأهل، قومیت، مذهب و سلامت در مدل داده وجود ندارند.** |
| رضایت و نگهداری | تاریخ و شرح رضایت متقاضی الزامی است؛ مدت نگهداری = رضایت + `retentionMonths` (پیش‌فرض ۲۴ ماه). کار زمان‌بندی‌شده رزومه‌های منقضی را بی‌نام و فایل‌هایشان را پاک می‌کند؛ «حذف به درخواست متقاضی» همین کار را فوری انجام می‌دهد. آمار (درخواست‌ها، مراحل، تاریخ‌ها) باقی می‌ماند. |
| فایل‌ها | بارگذاری با سرویس فایل هسته به نام ماژول، محرمانه؛ لینک دانلود فقط از مسیر ماژول (مسئول جذب یا مصاحبه‌گر همان متقاضی) و هر دانلود در Audit ثبت می‌شود. مسیر عمومی دانلود فایل هسته این فایل‌ها را نمی‌دهد. |
| جست‌وجو | متن کامل PostgreSQL (پیکربندی `simple`، پیشوندی) روی نام، موقعیت، خلاصه، سوابق، پروژه‌ها، تحصیلات و مهارت‌ها با نرمال‌سازی فارسی (ی/ک عربی، نیم‌فاصله، ارقام)؛ فیلتر مهارت، حداقل مدرک، حداقل سال سابقه (هم‌پوشانی دوره‌ها یک بار شمرده می‌شود)، سقف حقوق، شهر، وضعیت. |
| تکراری‌ها | قاعده‌ها: همراه یکسان، ایمیل یکسان، نام نرمال‌شده یکسان. ادغام: فیلدهای خالی تکمیل، سوابق/مهارت/فایل/درخواست منتقل (موارد یکسان یک بار)، رزومه دوم «ادغام‌شده» با اشاره به رزومه اصلی. |
| امتیازدهی | برای هر موقعیت شغلی، فقط این معیارها: مهارت/نرم‌افزار/گواهینامه/زبان با حداقل سطح، سال سابقه، حداقل مقطع و رشته، کلیدواژه در پروژه‌ها و سوابق، سقف حقوق، آمادگی شروع، شهر؛ وزن ۱ تا ۱۰. امتیاز ۰ تا ۱۰۰ با جدول «معیار/وزن/امتیاز/دلیل»؛ نسخه‌دار و با تغییر معیارها همه دوباره امتیازدهی می‌شوند. امتیاز فقط کمکی است. |
| قیف استخدام | مراحل قابل تنظیم (باز / استخدام / رد؛ بایگانی به‌جای حذف)، تاریخچه جابه‌جایی، دلیل رد الزامی؛ ثبت استخدام رویداد `recruitment.candidate.hired` منتشر می‌کند. |
| مصاحبه | فرم‌های ارزیابی قابل تنظیم (معیار و وزن)؛ مصاحبه‌گر اعلان می‌گیرد و فقط مصاحبه‌های خودش را با محتوای لازم رزومه (بدون اطلاعات تماس و حقوق) می‌بیند؛ امتیاز ۱ تا ۵ برای هر معیار، جمع‌بندی و یادداشت. |
| گزارش | رزومه جدید، استخدام، مصاحبه، میانگین روز تا استخدام، به تفکیک موقعیت، منابع جذب، دلایل رد؛ خروجی Excel/CSV و چاپ. |
| داشبورد و KPI | ویجت «استخدام» و «مصاحبه‌های من»؛ Providerهای `recruitment.hires`، `recruitment.time_to_hire`، `recruitment.open_jobs`. |
| سرویس عمومی | `recruitment.candidates@1`: `hired()` و `get(id)` برای انتقال انتخابی به ماژول پرونده کارکنان (بررسی مجوز با فراخواننده). |

## مجوزها
`recruitment.candidate.view` (مشاهده رزومه و فایل، ثبت می‌شود)، `recruitment.candidate.manage`، `recruitment.job.manage` (موقعیت، معیار امتیاز، مراحل، فرم‌ها)، `recruitment.application.manage` (قیف و تعیین مصاحبه)، `recruitment.interview.evaluate` (own: مصاحبه‌های خودتان)، `recruitment.report.view`. نقش‌ها: «مسئول جذب و استخدام» و «مصاحبه‌گر».

## محدودیت‌ها
- استخراج خودکار اطلاعات از فایل رزومه (PDF/Word) انجام نمی‌شود؛ ورود ساختاریافته دستی است.
- فرم عمومی ارسال رزومه از وب‌سایت شرکت (بدون ورود) ساخته نشده است.
- ساعت مصاحبه به وقت تهران است (A34).
