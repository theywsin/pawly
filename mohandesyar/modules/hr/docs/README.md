# ماژول پرونده کارکنان (`hr`)

| بخش | توضیح |
|---|---|
| پرونده | شماره پرسنلی (یکتا در شرکت)، نام، کد ملی (با کنترل رقم کنترلی، یکتا)، همراه، ایمیل، واحد، سمت، مدیر مستقیم، تاریخ استخدام، اتصال به حساب کاربری؛ ثبت پایان همکاری. |
| قرارداد کاری | نوع (دائم/موقت/پروژه‌ای/ساعتی/کارآموزی)، بازه (بدون هم‌پوشانی)، حقوق ماهانه، ساعت کار هفتگی. **محرمانه:** فقط با `hr.contract.view` و هر مشاهده در Audit ثبت می‌شود؛ هشدار یک‌باره پیش از پایان قرارداد (پیش‌فرض ۳۰ روز). |
| سوابق، مهارت‌ها، آموزش‌ها | سوابق (ارتقا، جابه‌جایی، تشویق، تذکر، تحصیلات، سابقه پیشین…)، مهارت/نرم‌افزار/گواهینامه/زبان با سطح، دوره‌های آموزشی با ساعت. |
| مرخصی | انواع قابل تنظیم با سقف سالانه (سال شمسی) و با/بدون حقوق؛ روزها بر پایه تقویم کاری سازمان (جمعه و تعطیلات شمرده نمی‌شوند)؛ کنترل مانده و هم‌پوشانی؛ تأیید با گردش کار هسته `hr.leave` (پیش‌فرض: نقش «مسئول منابع انسانی»)؛ انصراف درخواست در انتظار، گردش کار را لغو می‌کند؛ اعلان نتیجه به کارمند. |
| ارزیابی عملکرد | دوره، معیارهای وزن‌دار با امتیاز ۱ تا ۵ (امتیاز کل ۰ تا ۱۰۰)، نقاط قوت و بهبود؛ پیش‌نویس فقط برای منابع انسانی، نسخه نهایی غیرقابل تغییر و برای کارمند قابل مشاهده. |
| انتقال از بانک رزومه | فهرست متقاضیان استخدام‌شده (سرویس `recruitment.candidates`)؛ کاربر تک‌تک فیلدها و موارد را علامت می‌زند؛ هیچ داده‌ای خودکار منتقل نمی‌شود و حقوق مورد انتظار اصلاً پیشنهاد نمی‌شود. |
| خودخدمت | کارمند با نقش «کارمند (پرونده و مرخصی خود)» پرونده خود (بدون قرارداد)، مانده و درخواست مرخصی و ارزیابی‌های نهایی خود را می‌بیند. |
| داشبورد و KPI | ویجت‌های «کارکنان» و «مرخصی من»؛ Providerهای `hr.headcount`، `hr.training_hours`، `hr.leave_days`؛ سرویس `hr.employees@1` برای ماژول KPI. |

## مجوزها
`hr.employee.view` (own: پرونده خود)، `hr.employee.manage`، `hr.contract.view`، `hr.contract.manage`، `hr.leave.request` (own: برای خود)، `hr.leave.manage`، `hr.review.view` (own: ارزیابی نهایی خود)، `hr.review.manage`. نقش‌ها: «مسئول منابع انسانی» و «کارمند (پرونده و مرخصی خود)».

## محدودیت‌ها
- تأیید مرخصی با نقش انجام می‌شود، نه مدیر مستقیم هر کارمند (A43).
- مرخصی ساعتی و نیم‌روز، انتقال مانده به سال بعد و محاسبه حقوق و دستمزد ساخته نشده است.
- کد ملی و حقوق در سطح برنامه رمزنگاری نمی‌شوند؛ حفاظت با مجوز جدا، RLS و ثبت مشاهده است (A44).
