# ماژول مالی و کنترل بودجه (`finance`)

> سیستم مدیریتی-کنترلی است؛ جایگزین نرم‌افزار حسابداری رسمی یا سامانه مودیان نیست. همه فهرست‌ها خروجی Excel/CSV برای انتقال به نرم‌افزار حسابداری دارند.

| بخش | توضیح |
|---|---|
| حساب‌ها | بانکی (با شبای کنترل‌شده)، تنخواه (متصدی)، صندوق؛ مانده افتتاحیه؛ موجودی = افتتاحیه + گردش. برداشت بیش از موجودی ممکن نیست. |
| تراکنش | دریافت، پرداخت و انتقال؛ **پس از ثبت تغییرناپذیر** (trigger پایگاه داده حذف و ویرایش را رد می‌کند)؛ اصلاح فقط با «ابطال» که سند معکوس ثبت می‌کند. |
| انتقال بین حساب‌ها | دو ردیف به نوع `transfer` بدون سرفصل؛ در هیچ گزارش درآمد/هزینه شمرده نمی‌شود (قید ساختاری، نه فیلتر). |
| درخواست پرداخت | درخواست (کاربر الف؛ در محدوده پروژه‌های خود) ← گردش تأیید `finance.payment` با آستانه مبلغ و سقف اختیار نقش (کاربر ب…) ← اجرا با انتقال بانکی/نقد/چک (کاربر ج). اجراکننده نمی‌تواند درخواست‌دهنده یا تأییدکننده باشد (کنترل در برنامه و قید پایگاه داده). |
| مطالبات و بدهی‌ها | مبلغ، سررسید، تسویه جزئی با دریافت یا درخواست پرداخت، وضعیت باز/سررسیدگذشته/تسویه؛ یادآوری پیش از سررسید. فاکتور تأییدشده در ماژول تدارکات خودکار بدهی می‌سازد. |
| چک | دریافتی و صادره (از اجرای درخواست پرداخت)؛ وصول تراکنش ثبت می‌کند؛ برگشت و ابطال. |
| بودجه پروژه | نسخه اولیه و اصلاحی به تفکیک سرفصل؛ تصویب توسط فردی غیر از تهیه‌کننده؛ نسخه مصوب تغییر نمی‌کند. هزینه واقعی، تعهدات باز (دستی یا از سفارش خرید تأییدشده) و مانده قابل تعهد. |
| EAC | روش نسخه‌دار: `AC + (BAC − EV) ÷ CPI`، `AC + (BAC − EV)` یا `AC + ETC دستی`؛ EV = BAC × پیشرفت فیزیکی واقعی از ماژول پروژه؛ در نبود داده، دلیل نمایش داده می‌شود؛ یادداشت علت انحراف. |
| جریان نقدی | به تفکیک ماه شمسی؛ قطعی (مطالبات، بدهی‌ها، پرداخت‌های تأییدشده، چک‌ها) و تخمینی (پیش‌بینی دستی) جدا با مانده هر کدام. |
| مغایرت‌گیری | ورود صورت‌حساب CSV (تاریخ شمسی/میلادی، ارقام فارسی)، تطبیق خودکار بر پایه مبلغ، تاریخ (±۳ روز) و شماره پیگیری؛ تطبیق دستی. |
| گزارش و داشبورد | درآمد و هزینه به تفکیک سرفصل و پروژه؛ ویجت موجودی، سررسیدها و درخواست‌های پرداخت؛ Providerهای KPI: موجودی، درآمد، هزینه، مطالبات معوق. |

## مجوزها
`finance.account.manage`، `finance.transaction.view`، `finance.transaction.record`، `finance.transaction.void`، `finance.payment.request` (project)، `finance.payment.execute`، `finance.obligation.manage`، `finance.budget.view` (project)، `finance.budget.manage`، `finance.budget.approve`، `finance.reconcile`، `finance.report.view`. نقش‌ها: «مدیر مالی» (بدون اجرای پرداخت)، «مسئول خزانه»، «درخواست‌کننده پرداخت».

## محدودیت‌ها
- دفتر کل، سند حسابداری دوطرفه، مالیات بر ارزش افزوده و سامانه مودیان پوشش داده نمی‌شوند.
- ارز خارجی ندارد (فقط ریال).
- ورود صورت‌حساب فقط CSV/متن است (A49).
