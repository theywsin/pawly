# ماژول مدیریت هلدینگ (`holding`)

| بخش | توضیح |
|---|---|
| مقایسه شرکت‌ها | ماتریس شرکت × شاخص برای یک بازه؛ هر خانه همان لحظه از Provider شاخص ماژول مالک برای آن شرکت محاسبه می‌شود (هیچ عددی در این ماژول ذخیره نمی‌شود). «—» یعنی Provider داده‌ای ندارد. ردیف «کل هلدینگ»: جمع برای تعداد و ریال، میانگین ساده برای درصد و نرخ. |
| روند ماهانه | یک شاخص برای ۳، ۶ یا ۱۲ ماه شمسی اخیر به تفکیک شرکت. |
| نماهای ذخیره‌شده | مجموعه‌ای از شاخص‌ها با نام، برای تکرار سریع مقایسه. |
| دسترسی | فقط شرکت‌هایی که کاربر در **همان شرکت** مجوز `holding.view` دارد (`ctx.canIn` در هسته)؛ درخواست شرکت دیگر ۴۰۳ است. خروجی Excel/CSV از همان داده مجاز. |

## مجوزها
`holding.view`، `holding.manage` (ذخیره نما). نقش: «مدیر هلدینگ».

## وابستگی
ندارد؛ شاخص‌ها از هر ماژول فعالی که `kpiProviders` اعلام کرده باشد (پروژه، مالی، تدارکات، QHSE، منابع انسانی، CRM…) می‌آیند.

## محدودیت‌ها
- Providerها در سطح شرکت‌اند؛ تفکیک واحد/پروژه در مقایسه هلدینگ نیست.
- میانگین درصد/نرخ وزن‌دار (مثلاً بر پایه نفر-ساعت) نیست (A55).
