## ۳. ساخته‌شده‌ها

```
apps/api/migrations/core/0003_landing_signup.sql   لیدها، یادداشت لید، FAQ، محتوا، وضعیت pending سازمان، مشخصات شرکت
apps/api/src/platform/site.service.ts              داده عمومی سایت، لید و ضدهرزنامه، سیاست ثبت‌نام
apps/api/src/platform/public.controller.ts         /api/public/{plans,site,pages/:key,form-token,leads}
apps/api/src/app/app.factory.ts                    HTML با PUBLIC_ORIGIN، sitemap/robots، br/gzip، TRUST_PROXY
apps/web/src/areas/public/                         لندینگ و صفحات عمومی، فرم لید، meta
apps/web/src/entry-prerender.tsx, scripts/prerender.mjs, scripts/compress.mjs
apps/web/src/areas/app/Onboarding.tsx              جادوگر راه‌اندازی
apps/web/src/areas/console/{Leads,Plans,Content}.tsx  و سیاست ثبت‌نام/تأیید در Tenants
e2e/phase2.spec.ts, e2e/lighthouse.mjs
```

**اصلاحات حین تست:** صفحات داخلی `h1` نداشتند (اکنون هر صفحه یک `h1`)؛ اسکلت بارگذاری پلن‌ها جابه‌جایی صفحه (CLS ۰٫۳۱) ایجاد می‌کرد؛ zod با بررسی `eval` خطای CSP ثبت می‌کرد (`jitless`)؛ دکمه «فعلاً رد شو» پیش از پاسخ سرور هدایت می‌کرد؛ API هدر `X-Forwarded-For` را از هر کسی می‌پذیرفت و محدودیت نرخ قابل دور زدن بود (اکنون فقط از peerهای `TRUST_PROXY`).

| CI در GitHub | هنوز اجرا نشده است |

## ۵. پیش‌نیاز فاز ۳ و سؤال‌ها

1. **متن‌ها و هویت بصری:** متن‌های لندینگ (`areas/public/catalog.ts`) را بازبینی کنید؛ لوگو و رنگ سازمانی را بفرستید.
2. **ترتیب ماژول‌های فاز ۳:** پیشنهاد من: پروژه‌ها و CRM/قراردادها اول، همراه زیرساخت گزارش/خروجی (Excel/PDF) که هر دو به آن نیاز دارند.
3. **SMTP:** آیا سرور ایمیل سازمانی دارید؟ تأیید ایمیل و اعلان لید به آن وابسته است.
4. سؤال‌های باز گزارش فاز ۱ (S3 مرجع، مخزن جدا) هنوز پاسخ نگرفته‌اند.
