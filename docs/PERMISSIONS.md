# فهرست مجوزهای اندروید

| مجوز | نوع | دلیل | زمان درخواست | اگر داده نشود |
|------|-----|------|--------------|---------------|
| `POST_NOTIFICATIONS` | زمان اجرا (اندروید ۱۳+) | نمایش اعلان یادآور واکسن، دارو، نوبت دامپزشک و کارهای مراقبتی | فقط هنگام ذخیره اولین یادآور/دارو/نوبت، یا با لمس «فعال‌سازی اعلان»؛ پیش از آن، دلیل به فارسی توضیح داده می‌شود | یادآورها داخل برنامه (داشبورد، زبانه یادآورها، صفحه اعلان‌ها) نمایش داده می‌شوند و کادر راهنما برای فعال‌سازی دیده می‌شود |
| `SCHEDULE_EXACT_ALARM` | دسترسی ویژه (اندروید ۱۲+) | ارسال یادآور دارو و واکسن سر وقت | درخواست خودکار ندارد؛ کاربر از «تنظیمات › اعلان‌ها › هشدار دقیق» فعال می‌کند | زمان‌بندی تقریبی (`setAndAllowWhileIdle`) استفاده می‌شود که ممکن است چند دقیقه دیرتر برسد |
| `RECEIVE_BOOT_COMPLETED` | عادی | بازیابی زمان‌بندی یادآورها پس از روشن شدن گوشی | — (در نصب داده می‌شود) | — |

## مواردی که عمداً درخواست نشده‌اند

| مجوز | چرا لازم نیست |
|------|----------------|
| `INTERNET` | برنامه هیچ ارتباط شبکه‌ای ندارد |
| `CAMERA` | از برنامه دوربین سیستم (`ACTION_IMAGE_CAPTURE`) استفاده می‌شود |
| `READ_MEDIA_IMAGES` / `READ_EXTERNAL_STORAGE` | انتخابگر تصویر سیستم (`ACTION_PICK_IMAGES` در اندروید ۱۳+، `ACTION_GET_CONTENT` در نسخه‌های قبل) و Storage Access Framework بدون مجوز کار می‌کنند |
| `WRITE_EXTERNAL_STORAGE` | نسخه پشتیبان با `ACTION_CREATE_DOCUMENT` در محل انتخابی کاربر ذخیره می‌شود |
| `USE_EXACT_ALARM` | مخصوص برنامه‌های ساعت/تقویم است |
| `FOREGROUND_SERVICE` | سرویس پیش‌زمینه وجود ندارد |

## سایر اعلان‌های مانیفست

- `uses-feature android.hardware.camera required=false` — نصب روی دستگاه‌های بدون دوربین ممکن است.
- `queries` برای `IMAGE_CAPTURE`، `DIAL` و `VIEW` (الزام اندروید ۱۱+ برای پیدا کردن برنامه مقصد).
- اجزای صادرشده: فقط `MainActivity` (لانچر) و `SystemEventsReceiver` (رویدادهای سیستمی محافظت‌شده). `ReminderReceiver` و `PrivateFileProvider` صادر نشده‌اند.
